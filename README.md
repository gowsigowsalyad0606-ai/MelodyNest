# 🎵 MelodyNest

**Personal AI Kids Song Generator** — Create original Tamil and English children's songs.

## Features (v0.1)
- Song topic input
- Language selector (Tamil / English)
- Song style selector (Kids / Nursery / Lullaby)
- Duration selector (30s / 60s)
- Clean, responsive homepage UI

## Project Structure

## Getting Started
Open `index.html` in any modern browser. No build tools required.
